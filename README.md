# Speedbuild

Тренировка быстрой стройки в Minecraft. Выбираешь тему (или случайную), размер постройки, время и
количество референсов, а сайт собирает доску картинок в стиле Pinterest и запускает таймер.

- **Темы бесконечные.** Стиль × объект × условие («Готическая часовня в тумане», «Японская пекарня у
  реки»). Десятки тысяч сочетаний, у каждой темы свой номер, ссылкой на раунд можно поделиться.
- **Три размера:** маленькая (до 15×15), средняя (около 30×30), крупная (от 60×60). У каждого свои объекты.
- **Время:** без лимита или 3–60 минут. Полоска таймера похожа на шкалу опыта, в конце звучит сигнал.
- **Референсы:** Minecraft-постройки с Reddit (r/Minecraftbuilds, r/DetailCraft), фото реальных зданий
  с Wikimedia Commons (только Quality images) и Openverse. Можно смешать оба источника.
- **Unsplash и Pexels** подключаются бесплатными ключами на странице «Источники». С ними фото
  реального мира выглядят «как с Pinterest».
- История раундов хранится в браузере.

Это чистый HTML, CSS и JS: без сборки, без сервера, без зависимостей.

## Запуск у себя

```bash
python3 -m http.server 8000
# открыть http://localhost:8000
```

Модули ES не работают из `file://`, поэтому нужен любой локальный сервер. Если добавить к адресу
`?demo`, вместо поиска покажутся тестовые картинки.

## Публикация на GitHub Pages

1. Открой репозиторий на GitHub, вкладка **Settings**, слева **Pages**.
2. В **Build and deployment → Source** выбери **Deploy from a branch**.
3. В **Branch** выбери `main` и папку `/ (root)`, нажми **Save**.
4. Подожди 1–2 минуты и обнови страницу. Сверху появится адрес вида
   `https://<логин>.github.io/<репозиторий>/`.

Каждый новый коммит в `main` публикуется сам. Файл `.nojekyll` отключает обработку Jekyll, она не нужна.

## Файлы

| Файл | Что внутри |
| --- | --- |
| `index.html` | Все экраны: раунд, доска, история, источники |
| `css/app.css` | Стили |
| `js/themes.js` | Словари стилей, объектов и условий, генератор тем |
| `js/sources.js` | Поиск картинок: Reddit, Wikimedia, Openverse, Unsplash, Pexels |
| `js/app.js` | Интерфейс, таймер, история |

Чтобы добавить темы, допиши стили в `STYLES`, объекты в `OBJECTS` или условия в `MODS` в `js/themes.js`.
