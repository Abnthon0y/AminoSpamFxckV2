0. ОБЩАЯ ЛОГИКА — одинакова у всех четырёх паков
====================================================================

ФОРМАТ
- Полотно 800×2500 = 8 колонок × 25 рядов = 200 эмодзи. Это ровно лимит одного пака Telegram — заполняй до конца.
- Пустых рядов нет. Пустые клетки бывают только внутри крупного арта: это вырезанный силуэт, часть рисунка.

ОДИН ГЕРОЙ
- Весь пак про одного персонажа: лицо, эмоции, позы, одежда, его вещи и символы.
- Ничего постороннего: каждый предмет связан с героем (его еда, вещи, цветы, оружие, стихия, талисманы).

ПЯТЬ ТИПОВ КЛЕТОК (доля от 200)
1. Мини-арт 1×1 С ФОНОМ — кадр из аниме/игры/манги, квадрат, кроп по лицу или глазам. ≈ 30%
2. Чиби / стикер героя 1×1 БЕЗ ФОНА — фигурка целиком, по центру клетки. ≈ 15%
3. Предмет-мотив 1×1 БЕЗ ФОНА — по центру, с отступом 6–10 px, однотонно в палитре пака. ≈ 15%
4. Крупный арт БЕЗ ФОНА, разрезанный на 2×2…5×6 клеток — фигура, лицо крупным планом,
   часть тела или одежды, эффект (лёд, ткань, плащ). Клетки без фигуры остаются пустыми. ≈ 35%
5. Акценты — рамки-сердечки или круги, разделитель 1×2–1×3, мини-коллаж 2×2–3×3. ≈ 5%
- Текстовых баннеров в таких паках нет. Надписи — только если они есть на самом арте.

ОБРАБОТКА
- Единый цветокор на весь пак: 3–5 цветов палитры пака. Всё, что выбивается, — перекрасить или обесцветить.
- Фон УБИРАТЬ: чиби, предметы, крупные арты (фигура, части тела, одежда, эффекты).
- Фон ОСТАВЛЯТЬ: мини-арты-кадры (квадрат 1×1, без скругления, кроп по лицу) и мини-коллажи.
- Крупный арт режется по фигуре: где фигуры нет — пустая клетка. Получается «рваный» силуэт, это нормально.
- Фрагменты (ноги, юбка, рукав, плащ, шляпа, волосы) — отдельные крупные арты, лучше по диагонали.

КОМПОЗИЦИЯ (сверху вниз)
- Ряд 1 — «витрина»: 8 самых узнаваемых мини-артов и чиби, разных по типу.
- Дальше блоки по 3–6 рядов: крупный арт шириной 3–5 колонок у одного края + столбик мелких клеток у другого.
- Крупные арты идут зигзагом: слева → справа → слева. Два больших подряд у одного края нельзя.
- Рядом с каждым крупным артом ставь 1–2 предмета-мотива — это «воздух».
- Самый эффектный арт (лицо крупным планом 3×3–5×5) — в середине пака, ряды 9–18.
- Нижние 3–5 рядов — «полка предметов»: мотивы вперемешку с мини-артами и чиби.
- Соседние клетки не повторяют один кадр. Больше 2 мини-артов одного эпизода рядом не ставь.
- Тёмные и светлые клетки чередуй, чтобы пак не «слипался» в пятно.

ЭМОДЗИ (для поиска)
- Мини-арт и чиби — по эмоции: 😊 😢 😳 😠 😴 🥺 😏.
- Предмет — свой эмодзи: ☕ 🎀 📷 🌸 ❄️ 🏮.
- Крупный арт — один эмодзи на все его клетки, по смыслу арта.
- Пустые клетки силуэта — ▫️.

1. MIO AKIYAMA (K-On!) — «монохромная школьница»
====================================================================
ИДЕЯ: чёрно-белый пак с редкими красно-розовыми акцентами, уютные ретро-вещи, школа, кафе.

ПАЛИТРА: #111111 чёрный · #ffffff белый · #9a9a9a серый · акцент #c73b45 красный · #f3c6cf бледно-розовый.
ОБРАБОТКА: всё в ч/б (контраст +15%). Красный оставлять только на 5–10% клеток: страницы манги
с розовым, красная лента, щёки. Фон мини-артов — светло-серый или белый.

ГЕРОЙ: Мио в школьной форме (пиджак, юбка, гольфы); длинные чёрные волосы, чёлка; смущение, улыбка, испуг.

ПРЕДМЕТЫ-МОТИВЫ (без фона, ч/б):
  кафе — чашка чая, кофе, торт, рулет, парфе, онигири, капкейк;
  ретро — фотоаппарат, кассета, виниловая пластинка, телефон, телевизор, калькулятор, часы, песочные часы;
  милое — бантик, плюшевый мишка, игральные кости, наушники, глобус, энергетик;
  символы — «> <», «…» в облачке, спираль, кнопка.

КРУПНЫЕ АРТЫ:
  - лицо Мио крупным планом 3×3 (глаза + чёлка), в середине пака;
  - портрет с руками у щёк 4×5, слева, ряды 14–18;
  - фрагменты-силуэты: ноги в гольфах (1×2), юбка и пиджак (2×2–3×3), волосы, рука с предметом;
  - полоска страниц манги с розовыми акцентами 2×3 справа вверху.

РАМКИ: нет. Мини-арты — строгие квадраты без скругления.

НАСТРОЙКИ (жёсткие правила): удаление фона — решает ИИ; сердечки — нет; баннер макс. 3; разделитель макс. 3;
  эмодзи по умолчанию 🖤; цвета баннеров #111111 #ffffff.

ИДЕЯ ДЛЯ ИИ (вставь в композитор):
  Монохромный пак Мио Акиямы: всё в ч/б с редкими красными акцентами. Ряд 1 — витрина из кадров и чиби.
  Крупное лицо 3×3 в середине и портрет 4×5 слева внизу; фрагменты ног, юбки и волос — силуэтами без фона.
  Между артами — ретро-вещи и еда из кафе без фона. Внизу — полка предметов. Без текстовых баннеров.

5. ШАБЛОН ДЛЯ НОВОГО ПАКА
====================================================================
ИДЕЯ: <герой> — «<настроение в 2–4 словах>».
ПАЛИТРА: 3–5 цветов (основной, тёмный, светлый, акцент; акцент ≤ 10% клеток).
ОБРАБОТКА: <ч/б | тёплый фейд | холодный | насыщенный>; что обесцвечивать.
ГЕРОЙ: внешность (волосы, одежда, отличительный знак) + 4–6 эмоций.
ПРЕДМЕТЫ-МОТИВЫ: 15–30 вещей героя в 3–4 группах (еда / вещи / стихия-эффекты / символы).
КРУПНЫЕ АРТЫ: 1 лицо 3×3+ (середина) · 1–2 фигуры 4×5–4×6 · 3–5 фрагментов одежды/тела · 1 эффект на всю ширину.
РАМКИ: <нет | круги | сердечки цветные | сердечки ч/б> и сколько штук.
ЭМОДЗИ ПО УМОЛЧАНИЮ: один, в цвет пака.
ИДЕЯ ДЛЯ ИИ: 3–4 предложения: палитра → крупные арты и где они → мотивы между ними → рамки.
