# ✦ TG Studio — мульти-программа для Telegram

Темы, языки, эмодзи-паки, стикеры, пиксельные GIF и эстетичные тексты постов — в одном удобном
интерфейсе, с нейросетью (можно бесплатно и без API) и автоматическим созданием всего прямо в твоём аккаунте.

```
˖ ࣪ ⊹ 🎨 темы · 🔤 языки · ✨ эмодзи · 👾 пиксель-gif · 🖼 стикеры · ✍️ тексты ⊹ ࣪ ˖
```

## 🚀 Запуск

**Windows:** дважды кликни `start.bat` — он сам создаст окружение, поставит зависимости и откроет программу в браузере.

**macOS / Linux:**
```bash
./start.sh
```

Вручную:
```bash
pip install -r requirements.txt
python run.py            # откроется http://127.0.0.1:8765
```
Нужен Python 3.10+. Для анимированных эмодзи нужен ffmpeg — он ставится автоматически пакетом `imageio-ffmpeg`.

Необязательные пакеты (раскомментируй в `requirements.txt`):

| Пакет | Зачем |
|---|---|
| `playwright` + `playwright install chromium` | авто-загрузка языка на translations.telegram.org |
| `rembg[cpu]` | нейросетевое удаление фона (точнее встроенного алгоритма) |
| `vtracer` | настоящая векторизация PNG → SVG кривыми |
| `anthropic` | Claude API (если есть кредиты) |
| `cryptg` | быстрее загружает файлы в Telegram |

## 🧠 Как подключить нейросеть (с API и без)

Вкладка **«ИИ и аккаунт»**:

| Вариант | Цена | Что нужно |
|---|---|---|
| **Pollinations** | бесплатно, без ключа | ничего — работает сразу (лимит ~1 ответ в 30 с, программа сама ждёт) |
| **Claude Code CLI** | по подписке Claude **Pro/Max**, без API-кредитов | `npm install -g @anthropic-ai/claude-code`, один раз запустить `claude` и войти аккаунтом claude.ai |
| **Google Gemini** | бесплатный ключ | ключ на [aistudio.google.com/apikey](https://aistudio.google.com/apikey) |
| **OpenRouter / Groq** | бесплатные модели | бесплатный ключ; на OpenRouter модели с пометкой `:free` |
| **Ollama** | бесплатно, офлайн | [ollama.com](https://ollama.com), `ollama pull llama3.1` |
| **LM Studio / DeepSeek** | локально / дёшево | OpenAI-совместимый адрес |
| **Claude API** | платно | ключ с console.anthropic.com |
| **Без ИИ** | — | темы, раскладка и стикеры работают на алгоритмах |

> **Про Claude без API:** официальный способ без покупки API-кредитов — Claude Code CLI, который работает
> по подписке Pro/Max. Бесплатный аккаунт claude.ai подключить к программам нельзя — для этого нет
> официального способа. Для полностью бесплатной работы выбирай Pollinations, Gemini или Ollama.

Для картинок (баннеры, арты, пиксель-GIF) — **Pollinations** (бесплатно) или свой **Stable Diffusion**
(AUTOMATIC1111 / Forge, запущенный с флагом `--api`).

## ✈️ Вход в Telegram

1. Получи `api_id` и `api_hash` на [my.telegram.org → API development tools](https://my.telegram.org/apps) (бесплатно).
2. Во вкладке «ИИ и аккаунт» введи их и нажми «Сохранить».
3. Войди **по QR-коду** (Telegram на телефоне → Настройки → Устройства → Подключить устройство) — код не нужен.
   Или по номеру: код обычно приходит **не по SMS, а в само приложение Telegram** (служебный чат «Telegram»);
   если не пришёл — кнопка «Код не пришёл» запросит SMS или звонок.
4. Сессия хранится только у тебя в папке `data/`. **Никому не отправляй папку `data/`** — это доступ к аккаунту.

Для загрузки паков можно вместо аккаунта использовать своего бота (@BotFather) — тогда паки будут называться `имя_by_бот`.

## 🎨 Темы

- обои → палитра до **15 цветов** (k-means в пространстве CIELAB), правка каждого цвета, ползунки **оттенок / насыщенность / светлота / контраст**;
- **ИИ сама создаёт тему целиком** по описанию («клубничное молоко», «ночной Токио»): название, все 58 цветов
  интерфейса и обои, нарисованные нейросетью; **правка словами** («пузыри темнее», «акцент мятный»);
- 6 стилей алгоритмом (тонированные пузыри, сочный акцент, пастель, стекло, два акцента, монохром) и **уникальные темы нейросетью** по описанию;
- автоконтроль читаемости по WCAG: основной текст ≥ 7:1, вторичный ≥ 4.5:1 — кнопка «Авто-контраст» чинит всё сама;
- подробный редактор: 58 ролей в 10 группах (шапка, список чатов, счётчики, круглая кнопка, входящие/исходящие,
  галочки, поле ввода, меню, кнопки, переключатели, ошибки…) с поиском и живым предпросмотром;
- **тонкая настройка каждого ключа** Android (~450) и Desktop (~365) с прозрачностью, плюс свои ключи;
- экспорт: Android `.attheme` (с обоями), Desktop `.tdesktop-theme`, iOS `.tgios-theme`, палитра PNG;
- **«Создать в аккаунте»**: облачная тема (работает на Android, iOS, macOS, Desktop) + файловые темы → ссылки `t.me/addtheme/…`.

## 🔤 Языки

- исходные строки берутся прямо из Telegram (Android, iOS, Desktop, macOS, Telegram X) после входа;
- **замена символов**: готовые наборы (кириллица → ᥲᥱ᥆ᥴ, αβεκ, ᴀʙᴇᴋ; латиница → 𝗯𝗼𝗹𝗱, 𝓼𝓬𝓻𝓲𝓹𝓽, ᥲᥱ᥉thᥱtᎥᥴ…) + свои правила `а=ᥲ`, даже слоги;
- **нейросеть по описанию** («язык котика», «как дворянин XIX века») — пачками, с проверкой: если ИИ испортил плейсхолдер (`%1$s`, `{count}`, `**`, `\n`…), строка откатывается;
- предпросмотр на макете интерфейса и проверка любой строки;
- экспорт `strings.xml` / `Localizable.strings` / `lang.strings`;
- **авто-загрузка на translations.telegram.org**: программа открывает браузер, ждёт подтверждения входа в приложении Telegram (один раз), создаёт язык и загружает строки.

> У translations.telegram.org нет публичного API, поэтому загрузка работает через управление браузером.
> Если сайт поменяет вёрстку и шаг не найдётся, задача встанет на паузу: сделай шаг руками в открытом окне и
> нажми «Продолжить». Для Desktop язык можно подключить и без сайта: Настройки → зажми **Alt+Shift** и кликни
> «Язык» → выбери `lang.strings`.

## ✨ Эмодзи-паки

- полотно **800×2500** = сетка 8×25 ячеек по **100×100** (8 в ряд, как в панели эмодзи);
- **ИИ-раскладка** по описанию: решает, где убрать фон, что сделать крупным артом, одиночным эмодзи,
  баннером **2–4×1** или разделителем **1×2+**, подбирает эмодзи и подписи; есть и алгоритмическая авто-раскладка;
- редактор: перетаскивание с привязкой к сетке, изменение размера, закрепление 🔒, точный рендер, вид «как в Telegram»;
- блоки: эмодзи, арт, баннер (с текстом, градиентом, любым шрифтом), разделитель, **коллаж**, текст, пустышка;
- **сердечки-рамочки**: картинка в форме сердца или рамка, «стирающая» центр, в **ч/б** — автоматически уходят
  в отдельную плашку (отдельный пак), можно одиночные и широкие; опция «адаптивный цвет» перекрашивает их под тему;
- формы: сердце, круг, звезда, арка, цветок, облако, ромб; обводка, скругление;
- **GIF → анимированные эмодзи** (WEBM VP9 с прозрачностью, ≤ 3 с, ≤ 256 КБ), крупный GIF режется на синхронные тайлы;
- экспорт PNG/WEBP, **SVG** и **TGS** (вектор Lottie — самое чёткое качество в Telegram);
- нейросеть рисует баннеры, арты и иконки прямо в пак;
- пак создаётся сам и называется так, как ты назовёшь (до 200 эмодзи в паке).

> Telegram не принимает SVG напрямую: векторный формат эмодзи — TGS. SVG пригодится для правки и печати.
> Для фото настоящие кривые даёт `vtracer`, без него SVG собирается «пиксельным вектором».

## 👾 Пиксельные GIF

Промпт → пиксель-арт 12–48 px с анимацией: блёстки, прыжок, парение, пульс, сердцебиение, мерцание, блик,
радуга, тряска, поворот, глитч. Режимы: ИИ-художник (Pollinations/SD → пикселизация), ИИ рисует пиксели сам
(можно и все кадры), встроенные шаблоны (без интернета), из своей картинки. Выход: GIF, WEBM 100×100, TGS, SVG, PNG.
Готовая гифка сразу попадает в библиотеку для композитора паков.

## 🖼 Стикеры

1:1 512×512 с умным кадрированием, вырезание объекта, **автокоррекция** (баланс белого, уровни),
**единый стиль пака** (перенос цвета в LAB), **LUT-фильтры** — 10 встроенных, свои `.cube` и HALD-картинки
(`.png`), яркость/контраст/насыщенность/теплота, рамки: обводка-стикер, тень, круг, сердце, арка, полароид,
плёнка. ИИ может подобрать эмодзи к каждому стикеру. Сборка в WEBP и загрузка пака.

## ✍️ Тексты постов

- **ширина строки** (8–80 символов) с авто-переносом, выравнивание влево/по центру/вправо брайль-пробелом `⠀`
  (обычные пробелы Telegram съедает), учёт «широких» эмодзи и иероглифов;
- «шрифты» Unicode к выделению: 𝐁𝐨𝐥𝐝, 𝘐𝘵𝘢𝘭𝘪𝘤, 𝙼𝚘𝚗𝚘, 𝓢𝓬𝓻𝓲𝓹𝓽, 𝔻𝕠𝕦𝕓𝕝𝕖, sᴍᴀʟʟ ᴄᴀᴘs, ᵗⁱⁿʸ, Ⓒⓘⓡⓒⓛⓔ, 🆂🆀🆄🅰🆁🅴, ᥲᥱ᥉thᥱtᎥᥴ,
  кириллица → αβεκ / ᥲᥱ᥆ᥴ; зачёркивание, подчёркивание и др.;
- библиотека символов (блёстки, сердца, скобки, стрелки, «древние» 𓏲 𓂃, цветы…), каомодзи, разделители
  (подгоняются под ширину), рамки, шаблоны (шапка, био, список, цитата, анонс), эмодзи-наборы,
  генератор «россыпи» символов, избранное ★ и заметки;
- **нейросеть**: пост на тему, оформить мой текст, ники, био, разделители — в стилях soft, dark, минимализм,
  k-pop, коттеджкор, россыпь, y2k, рамки. Надёжный режим: ИИ пишет смысл, а оформление собирает программа;
- предпросмотр как в Telegram (тёмная/светлая), счётчик и лимиты 4096 / 1024,
  копирование текстом, **с форматированием** (цитата/жирный — для Telegram Desktop/Web) и HTML для ботов.

## 📜 Правила

Отдельный раздел (и кнопка «📜 Правила раздела» в шапке каждого пункта). Для каждого раздела — **Общие, Темы,
Языки, Эмодзи, Пиксель-GIF, Стикеры, Тексты** — есть два вида правил:

- **правила для нейросети** — пишешь обычным языком («только пастельные цвета», «кнопки не длиннее 12 символов»,
  «после каждого баннера — ряд из 8 мелких эмодзи»); они добавляются к каждому запросу ИИ этого раздела, общие — ко всем;
- **жёсткие правила** — программа соблюдает их сама, даже без ИИ:

| Раздел | Жёсткие правила |
|---|---|
| Общие | язык ответов ИИ, запрещённые символы/слова (вычищаются из текстов и языков) |
| Темы | только тёмные/светлые, контраст строже WCAG на N%, закреплённые цвета `accent=#ff8fc4`, разрешённые стили |
| Языки | замены слов `Чаты => Мурчатики`, точные значения по ключам, приставка/окончание ко всем строкам, лимит удлинения строк ИИ |
| Эмодзи | эмодзи по умолчанию, удаление фона (авто/всегда/никогда), макс. ширина баннера и высота разделителя, ч/б сердечки, цвета и шрифт баннеров |
| Пиксель-GIF | палитра (рисовать только этими цветами), цвет контура |
| Стикеры | эмодзи по умолчанию |
| Тексты | замены, запрещённые символы, обязательная шапка и подпись, ширина строки по умолчанию |

Наборы правил можно сохранять под именем («нежный пак», «тёмный канал») и переключать одним кликом.

## 📁 Где что лежит

```
tg_studio/
  app/          — сервер и вся логика (Python)
  static/       — интерфейс (HTML/CSS/JS)
  data/         — настройки, правила, сессия Telegram, загруженные картинки (не публикуй!)
  output/       — готовые темы, паки, архивы
  luts/         — твои .cube / HALD-фильтры
  fonts/        — свои шрифты для баннеров (.ttf/.otf)
```
